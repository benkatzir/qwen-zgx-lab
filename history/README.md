# Historical experiment material

- The current validated recipe and all measured results are in the [main README](../README.md).
- These notes preserve the research process, earlier configurations, proposed experiments, and session checkpoints. Predictions and untested proposals are not measured results.
- `SESSION.md` is a chronological lab journal, not the conversation transcript. Old process IDs and active-run statements are historical; see the final checkpoint.

- Collection, packaging and setup helpers assume the original workspace/node paths. They are archival tools, not a portable installer.
- `run_fp8_mtp3.sh` and `run_quality_after.sh` are obsolete launchers; do not use them to reproduce the current recipe.
